# Bun source extractor

Recover JavaScript from a retained Bun source container without executing it.

## Setup

Use Node 22.18 or Node 24.11 and later. Install the parser from the repository root:

```sh
npm ci --ignore-scripts
```

## Extract

```sh
python3 decompile.py extract /path/to/bundle.js.gz /path/to/new-source
```

The input may be a compressed container or plain compiled application source. The extractor finds the supported Bun source member, parses complete statements and writes ordered program partitions. It also preserves builtin source members, marking Bun host syntax separately. The manifest records input hashes, original byte ranges and output hashes.

Existing output directories are rejected. Use `--repair` only for a preserved extraction tree; it replaces generated partitions and retires stale generated files.

## Assemble JavaScript

```sh
python3 decompile.py rebuild /path/to/source --no-header -o /path/to/application.js
```

Assembly requires the parser-validated manifest and every application partition. It validates the complete JavaScript program before writing an output. Missing files produce an error.

Native executable rebuilding requires the complete original Bun layout and metadata. A runtime header concatenated with edited JavaScript cannot supply that metadata. No native executable is generated by this tool.

The recovered application still relies on its original runtime dependencies. Parser-valid source establishes syntax and source recovery; it does not establish a working standalone desktop app.

## Tests

```sh
python3 test-decompile.py
```

Tests cover complete statement boundaries, embedded delimiters, byte-preserving assembly, traversal rejection, missing partitions and native rebuild rejection.
